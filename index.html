-------------------------------------------------------------------------------- # ARTISANLINK-AI An AI-powered digital marketplace assistant for traditional artisans and craft makers. ARTISANLINK-AI turns a mobile photo and a few spoken words into a proper product listing — with a clear description, a craft story, a fair price range, a cleaned-up photo and a ranked list of buyers who want that kind of craft. ## Features - **Artisan onboarding** — 3-step registration (language, personal details, craft details). - **AI product descriptions** — turns the artisan's own words into a clear, honest listing (title, short description, full description, keywords, category). Never invents history, awards or certifications. - **Craft story writer** — a short, warm story built only from the details provided. - **Fair price assistant** — cost + time + category margin + bulk logic gives a recommended price range with plain-language reasons. - **Photo clean-up** — in-browser brightness / contrast / saturation pass so a simple mobile photo looks closer to a studio shot. - **Image compression** — every upload is resized and compressed before saving, so the app works on slow connections. - **Buyer matching** — buyers (boutiques, exporters, hotels, restaurants, retail, corporate gifting, government, online sellers) ranked by category, material, price fit and location, each with reasons. - **Buyer requests** — accept or decline order enquiries, with quantity, offered price and total order value. - **Craft passport** — a printable certificate of handmade origin for each product. - **Multilingual** — English, Hindi, Telugu, Tamil, Kannada, Malayalam, Marathi, Bengali. Product text can be translated on demand. - **Voice support** — speak instead of typing, and listen to text read aloud, in the chosen language. - **Admin view** — verify artisans, approve or hide products, platform totals. - **Demo mode** — sample artisan, products, buyers and requests so the app can be demonstrated offline; AI falls back to a clearly labelled sample writer when no AI key is configured. - **Responsive** — sidebar on desktop, bottom navigation on mobile, large touch targets and readable type for low-literacy users. ## Technology - **React 19 + TypeScript** - **TanStack Start / TanStack Router** — file-based routing, SSR and server routes - **Vite 7** build tooling - **Tailwind CSS v4** with a warm terracotta/cream semantic design system (`src/styles.css`) - **shadcn/ui** components - **Lovable AI Gateway** (`/api/ai` server route) for description, story and translation - **Browser Web Speech API** for voice input and read-aloud - **Canvas API** for image compression and photo clean-up - **localStorage** local-first data layer (shaped like the server collections, so it can be swapped for a hosted database without touching the UI) ## Project structure ``` src/ routes/ __root.tsx app shell, fonts, providers index.tsx landing page login.tsx register.tsx auth flows dashboard.tsx artisan home products.index.tsx catalogue products.add.tsx AI-assisted listing flow products.$id.tsx product detail, translation, quick edit products.$id.passport.tsx craft passport buyers.tsx buyer matching requests.tsx buyer requests inbox profile.tsx settings.tsx language.tsx help.tsx admin.tsx api/ai.ts AI endpoint (description | story | translate) lib/ store.tsx local-first data layer ai.ts AI client, fair price, buyer matching demo-data.ts types.ts image.ts components/ layout.tsx protected.tsx common.tsx ui/* hooks/use-speech.ts ``` ## Getting started ```bash npm install npm run dev ``` Open the app, then log in with a demo account: - Artisan: `demo@artisanlink.ai` - Admin: `admin@artisanlink.ai` ## AI configuration `/api/ai` uses the `LOVABLE_API_KEY` environment variable (read server-side only, never exposed to the browser). When no key is present — or the AI is rate-limited or out of credits — the endpoint returns clearly labelled sample text so the app keeps working offline and during demos. ## Design principles - Large text, big buttons, plenty of contrast, icons plus words. - No invented facts about a craft or artisan. - The artisan always sets the final price. - Works offline-first; data stays on the device. ================================================================================ -------------------------------------------------------------------------------- FILE: public/robots.txt Lines: 15 -------------------------------------------------------------------------------- User-agent: Googlebot Allow: / User-agent: Bingbot Allow: / User-agent: Twitterbot Allow: / User-agent: facebookexternalhit Allow: / User-agent: * Allow: / ================================================================================ -------------------------------------------------------------------------------- FILE: src/styles.css Lines: 176 -------------------------------------------------------------------------------- @import "tailwindcss" source(none); @source "../src"; @import "tw-animate-css"; @custom-variant dark (&:is(.dark *)); /* * ARTISANLINK-AI design system. * Warm earthy palette: terracotta, brown, cream, soft green. * All colors are oklch semantic tokens.
